# Instructor Effectiveness Modeling

A machine learning project that analyzes educational data to estimate instructor effectiveness using learner outcomes, engagement, and feedback metrics.

## Objectives
- Perform exploratory data analysis (EDA)
- Define an Instructor Effectiveness Score
- Aggregate batch-level data to instructor level
- Train ML models to predict effectiveness tiers
- Interpret model results and discuss limitations

## Tech Stack
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Key Learnings
- Feature engineering
- Data aggregation
- Classification models
- Model evaluation
- Ethical considerations in educational analytics
